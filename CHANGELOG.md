# Changelog

- Première version publiée sur GitHub : page d'accueil, Harf (arabe égyptien) et Aspi (copte).

- Aspi : textes des prières vérifiés avec le livret de la messe, leçon « Suivre le livret », prononciation en franco.
- Quiz : plus de réponses ambiguës (deux bonnes réponses possibles) et 4 choix par question dans les leçons.
- Installation sur téléphone et fonctionnement hors ligne.
